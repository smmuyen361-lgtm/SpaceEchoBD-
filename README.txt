# SpaceEcho BD — Forgotten but Not Lost

A simple static website prototype for a NASA Space Apps Challenge storytelling project about equipment left behind on the Moon and Mars.

## Files
- `index.html` — the website homepage
- `README.txt` — this project note

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload `index.html` to the root of a public GitHub repository.
2. Open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for deployment to finish, then use the URL shown in Pages settings.

## Important
This is a starter prototype, not a complete research submission. Verify facts, add original analysis/storytelling, credit NASA sources and images, and follow the challenge submission requirements.
